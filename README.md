SauceDemo Playwright Automation Testing
Project Overview

This project contains automated test cases for the SauceDemo web application using Playwright with JavaScript.

The purpose of the project is to automate important functional test scenarios such as login, product listing, cart, checkout, and UI/navigation functionality.

Website under test: SauceDemo

Technologies Used
Playwright
JavaScript
Node.js
Visual Studio Code
Page Object Model (POM)
Chromium, Firefox, and WebKit
